# Phase 3C-FIX2 · 三种交通共用首页置顶

巴士、港铁和轻铁统一使用三个首页位置。收藏和置顶分开操作。收藏页的上移／下移交换相邻的全局位置，即使筛选后相邻项目属于未显示的交通类别。满额时提示先取消一项置顶。取消置顶保留收藏，取消收藏同时释放位置。

## 数据审计与升级

旧版巴士将置顶名次写入 `bus_favorites.pin_order`。铁路收藏以交通类型、线路和站点作为复合键，原先没有置顶字段。Phase 3C 自动预览最近收藏的最多两项铁路服务。

v10 迁移在同一个 SQLite 事务内建立 `home_transport_pins`。旧收藏表、历史迁移和旧栏位原样保留。

1. 按旧巴士名次导入全部巴士置顶，保留相对顺序。如旧名次有空档，按原顺序连续编号。
2. 将之前自动预览的最近两项铁路收藏依序补入剩余位置。收藏时间相同时，以交通类型、线路、站点排序。已有三个巴士置顶时，所有铁路收藏仍留在收藏页。
3. 新表将位置限制在 1–3，并分别对巴士 ID 和铁路复合键设唯一约束。迁移完成后由 `user_version` 跳过再次导入。重新打开数据库保留用户后来设定的顺序。
4. 删除收藏时由 SQLite trigger 同一事务删除置顶。App 内置顶、排序和交通收藏写入经过共用队列。随后新增的收藏等待用户主动置顶。
