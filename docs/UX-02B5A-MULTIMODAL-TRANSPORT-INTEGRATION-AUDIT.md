## 搜尋與交通切換

- 「全部」無搜尋詞時顯示真實附近巴士。輸入後使用一個受 80 字元限制的搜尋框，依次排列巴士、港鐵、輕鐵，各自使用既有匹配規則。搜尋文字在本機比對，巴士網絡取得的是整個營辦商目錄。每字不會重新建立網絡查詢。初次進入沒有搜尋詞時，不讀取文字搜尋所需的巴士目錄。
- 共同搜尋詞預期在全部、巴士、港鐵、輕鐵之間保留，切換即以現行來源重新計算。未接入模式隱藏搜尋框，離開後可沿用原詞。`Bus → MTR → Light Rail → Ferry → All → Bus` 已用關閉定位服務、目錄延遲後失敗的隔離環境重現。`Yuen Long` 分別保留港鐵 `YUL` 及輕鐵 `600`，遲到的巴士結果狀態不替換鐵路列。All 保留鐵路結果及巴士目錄錯誤，鐵路無匹配和巴士未能載入分開顯示。
- 「按路線／按車站」在無搜尋詞時可切換。全部和巴士共用巴士展示模式，兩個鐵路目錄各保留自己的最近模式。搜尋期間直接顯示該來源的匹配項目，清除／取消後恢復所選來源目錄。用戶更改交通類別、展示模式、距離或搜尋詞時可回到新列表起點。手動選地標及明確使用目前位置沿用既有規則重設至 500 米，普通返回或自動刷新保持距離。
- 混合搜尋按結果類型分派導航。港鐵與輕鐵鍵帶 `kind`，巴士鍵帶營辦商路線身份，同名站或號碼相近不會互相覆蓋。現有打包巴士站序索引與 11 條輕鐵常規路線未發現完全相同的號碼。這項檢查只覆蓋打包索引，後續營辦商目錄新增同號時仍由類型區分。
