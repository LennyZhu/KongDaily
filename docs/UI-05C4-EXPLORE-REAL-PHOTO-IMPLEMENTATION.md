## 下载、转换及哈希

2026-11-20 首轮取得官方 DVIDS 的 2000w 公开衍生图、五份 Wikimedia 标准 1280 px 衍生图及 Unsplash 全尺寸西九 JPEG。首轮部分 Commons 全尺寸请求返回 HTTP 429，改用官方缩图主机。UI-05C4A 单独下载山頂花園全尺寸 JPEG，以 Commons SHA-1 对照确认后记录 SHA-256。西九与山頂花園具备全尺寸下载文件 SHA-256，另六张仍保留原文件 URL、修订号、Commons SHA-1 及所取得官方衍生文件的 SHA-256。所有下载文件和优化文件分别记录。 [机器可读来源、许可、处理记录及哈希](../assets/explore/photos/attribution.json)

用 macOS Core Graphics／Image I/O 按原方向读入并编码为 sRGB JPEG，质量参数 0.73，省略原 EXIF。龙脊从左上角截取 1999 × 770 再缩至 1480 × 570。西九和山頂花園等比例缩至 1480 px 长边，其余保持下载衍生图的 1280 px 长边再编码。列表及详情使用中心 `cover` 裁切，已在本地以 66 px 方框及 372 × 142 px 横框逐一查看。八张合计 3,631,704 bytes。

## App 接入及旧素材

- `src/explore-place-images.ts` 以现有正式地点 ID 作静态 `require()`，列表和详情共用同一文件。原有卡片尺寸、圆角、分类、文字、点击区及详情导航保留。详情图片有繁中及英文场景说明，列表缩图不重复读出卡片名称。
- 各详情有「照片署名／Photo credit」入口，按正式 ID 将相应作品置顶。山頂花園新增作者要求的缩图旁署名，详情入口紧邻主图并显示作者名。数据来源及图片署名页保留原有官方来源、首页 Kevin Huynh 的维港 Pexels 照片和 Jeanne Rose Gomez 的西九 Unsplash 照片。它们仍供首页使用，与探索的艺术公园新图分别注明。

## iPhone 人工验收

1. 在探索列表查看八张实景图，切换四个分类，确认跨分类的同地点用同一图。检查山頂花園草坪和凉亭的裁切，以及缩图旁的作者署名。
2. 打开八个详情，检查原场景、缩图和横框裁切，验证繁中／English 及 VoiceOver。打开「照片署名」，核对作品、摄影者、许可和改动。龙脊的非背书声明及山頂花園的 CC BY 4.0 条款须可查阅。
3. 用飞行模式打开这些详情和署名。然后由首页龙脊卡、全域搜索结果进入详情，核对返回及现有交通、导航行为。
4. 准备商店素材前检查截图是否仍含旧龙脊图。所有照片可用、来源可追溯并通过 8／8 验证后再继续整体素材审批。
