# UX-02A1 附近交通首屏收尾

**UX-02A1 已完成實作與自動化驗證，iPhone 人工驗收尚待開發者確認。**

## 首屏調整

原畫面把原生導覽列留空，再以最小高度 104pt 的獨立天際線卡顯示標題與說明。標題疊在照片上，位置卡、篩選及列表間距也使第一張巴士卡出現較靠下。按開發者的人工驗收意見調整如下。

| 區域 | 調整 |
| --- | --- |
| 原生導覽 | 「附近交通 / Nearby transport」移入既有原生導覽列，深色標題配純色淡青背景。沿用原生返回、Status Bar 及安全區。 |
| 頁面說明 | 用原有字級呈現一段可換行說明，右側保留低透明度維港天際線。說明文字有淡青底，長文字延伸時仍易讀。說明高度由內容決定。 |
| 參考位置 | 只壓縮卡片上方內距與位置列下方留白。四個既有位置文案、定位按鈕及地標展開仍在原處。 |
| 模組間距 | `/transport` 列表的頂部留白由 16pt 減至 4pt，頁首模組間距由 12pt 減至 8pt。沿用 44pt 觸控目標、直線距離與資料覆蓋說明、列表底部安全區及卡片資料。 |
| 路線搜尋 | 篩選下方使用整行可點按入口，兩種文案都復用原 `/bus` 的查詢流程。 |

## 橫向篩選與搜尋

七個交通方式沿用原膠囊、現有圖標和海港青選中狀態。單一橫向列可手動滑動，超出視窗時以邊緣淡化及獨立 44×44pt 箭頭提示。點按箭頭向後滑一段，滑到末端時箭頭可返回開頭。當整列放得下時不顯示箭頭。膠囊寬度按視窗留出空間，極大字時可在膠囊內自然換行，保留 VoiceOver 選中語義。

| 選擇 | 搜尋入口 | 附近結果 |
| --- | --- | --- |
| 全部 / All | 搜尋交通路線 / Search transport routes，開啟 `/bus`。 | 已接入的真實巴士結果。 |
| 巴士 / Bus | 搜尋巴士路線 / Search bus routes，開啟 `/bus`。 | 原有巴士路線與車站、ETA、限定服務、有效成人車費。 |
| 港鐵、輕鐵、渡輪、電車、專線小巴 | 入口隱藏。 | 原 UX-02A 未接入狀態。 |

箭頭只捲動篩選列。選擇交通方式仍使用原頁面的模式狀態，未改變 UX-01A 自動定位、回焦／回前景更新、手動地標優先、權限與錯誤處理及距離排序。沿用 UX-01B ETA 分類、限定服務與 UX-01C 車費身份校驗、全程／此站區分、到期隱藏及 68X 安全回落。舊 `/bus/nearby` 仍使用原本的版面間距。

## iPhone 人工驗收

1. 在 iPhone 17 Pro 和較小的 iPhone 由首頁開啟交通查詢，核對標題清楚、說明可讀、天際線在右側低調可見、首張可用路線卡比原畫面更早出現。測試原生返回及邊緣手勢。
2. 在繁中、English 和較大系統字體下手動滑過整列篩選，再點按箭頭往返，確認首尾項目可完整讀取並選擇。用 VoiceOver 檢查箭頭動作與各個選中狀態。
3. 分別從「全部」及「巴士」點按搜尋，核對文案與原巴士查詢。切換到其餘五個方式，確認只有相應未接入狀態。
4. 在已授權狀態進頁，核對自動定位、手動地標及按路線／按車站。核對直線距離說明、有效 ETA、限定服務、成人車費和底部安全區。

測試使用程式渲染和模擬佈局事件。兩種 iPhone 的實際排版、天際線可見程度、VoiceOver、滑動及原生手勢待人工確認。
