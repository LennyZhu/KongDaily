### 返回與設施跨 Tab 的風險

- 以倉庫實際路由檔生成導航設定，用已安裝 Router 的狀態工具核對巴士路線、巴士站、探索詳情三個 Stack 目標。三者解析到正確路由與原始參數，返回動作指向原 `search` route key。SRCH-01B 將關鍵詞、篩選、當前結果及捲動留在該 Stack 實例；結果更新時以穩定列鍵保留可見結果錨點，使用者改詞或切類才重置列表。現況沒有結果列，真實捲動及原生返回仍待後續驗收。
- 收藏 → 附近是在已掛載的 Tab 內切換。以同樣參數從根 Stack 的 `/search` 呼叫 `navigate('/nearby')`，狀態推演得到 `(tabs) → search → (tabs)`，最上方是另一個 Tab Stack entry，使用另一個 route key。雖然同一狀態推演的 `GO_BACK` 能返回搜尋，Tab 容器設定隱藏 Stack 標題，原生可見返回、Tab 狀態、焦點及手勢均未驗證。直接照搬收藏導航會有兩份 Tab 狀態的風險。
- 若要求統一的原生返回，建議批准一個薄的 Stack 路由包裝既有附近選點地圖與卡片，從搜尋 push，返回 pop；共用單次識別與聚焦邏輯，原有四個 Tab 仍各只有一份。SRCH-01B 先做路由原型，核對 MapKit、Safe Area、浮動 Tab 留白和 GPS 行為。若產品要求一定進原「附近」Tab，應明確批准跨 Tab 切換並設計返回搜尋及恢復捲動，作為另一種返回合約。[四 Tab 設定](../src/app/%28tabs%29/_layout.tsx) · [現有跨 Tab 測試](../scripts/test-facility-favorites.cjs)

## 5. 1.0 最小搜尋規則

1. 輸入 80 字元上限，以 Unicode NFKC 正規化、合併空白、去除首尾空白，兩語一律可搜；英文比對忽略大小寫。可統一常見直／彎引號，讓 `Dragon's Back` 能命中正式標題 `Dragon’s Back`。一個英數字可作路線前綴；名稱從兩個英文字母／數字或一個漢字開始。搜尋字串保持原樣供輸入框顯示。
2. 路線號精確優先、前綴其次。現有 `matchBusRoutes` 還會匹配路線號中段；全域頁應為這個規則加輕量模式或過濾，維持原專項巴士搜尋。輸入中文或英文名稱時匹配營辦商、起訖及嶼巴官方全名。實測 `１` 命中九巴／城巴兩個身份，`268x` 可保留服務 3。`九巴 1` 目前不會被拆成營辦商與路線號，若要求此語法應納入 SRCH-01B 驗收。
3. 各類內按完整名稱、名稱前綴、名稱包含、其他已索引欄位排序；多詞可用本地設施匹配器的逐詞規則。命中等級相同時按既有路線自然順序、雙語標題或固定內容順序，再以穩定鍵排序。區域文字可匹配實際收錄的地區欄位。普通公園和另一個官方寵物設施即使同址同名，仍保留其官方身份；地點跨分類按同一 `place.id` 去重。香港公園可分別作為附近設施及精選內容命中，分組名稱明確提示兩種入口。
4. 「全部」首屏每組最多 **8 筆**（四組合計最多 32）。切入單類後，路線或站點最多 **30 筆**，設施沿用既有 **15 筆**上限，探索最多 **8 筆**。顯示「已列 N／M 筆」及「查看此類」；單類仍有餘量時提示縮窄關鍵詞。M 僅指本機可用資料的命中數。例 `公園` 實測命中設施 226 筆，現有搜尋器只回傳 15 筆。
5. 以查詢頁實例按需建立一次正規化名稱索引，隨資料版本或目錄更新重建。用可取消的短防抖／延後本機匹配處理連續輸入，結果以查詢及資料代號隔離；合併成單一可虛擬化的 `SectionList`，限制排序及結果渲染量。正式設施索引共 673,397 bytes，Registry 共 787,102 bytes，站點種子 714,784 bytes，反向索引 623,550 bytes，探索 JSON 37,532 bytes。沿用現有資產與 SQLite，避免逐鍵讀全庫或重新正規化；反向索引留至站點頁按需讀取。iPhone 首次載入、連續輸入和回到列表的實際延遲應在 SRCH-01B 量測。
6. 全域頁開啟或首次進入巴士查詢範圍時，可啟動一次既有目錄載入流程；重試僅處理失敗來源。輸入處理只做本機比對。當次查詢不傳至地政總署；獨立地區／地址搜尋可明確指往現有「附近」的專項搜尋。全域頁不預先查詢 ETA 或請求位置權限。

## 6. UI 資訊架構及狀態

- **頂部**沿用 Root Stack 和搜尋框，有清除、搜尋鍵及 VoiceOver 標籤。建議把承諾調整為「搜尋巴士路線、車站、設施或精選地點」，English 對應同一範圍。是否同步微調首頁入口文案由產品批准。
- **篩選**建議「全部／巴士路線／巴士站／附近設施／精選地點」。設施及探索列標示類別／區域；巴士路線列標示營辦商和可核實方向或變體，巴士站列保留營辦商。沿用暖白底、海港青、白色圓角列及現有圖示，支援 44pt 觸控、大字自然換行、雙語及群組標題。
- **空白輸入**顯示簡短範圍與範例，例如 `268X`、`香港公園`、`Dragon’s Back`。只有符合最小輸入條件的分組開始查詢。清除回到起始狀態。
- **無命中**須在相關分組均已讀取後顯示「找不到符合的結果」及縮窄或換詞提示。巴士目錄未能取得或個別營辦商超時／失敗時，保留已有結果，分組標示「巴士路線目錄暫未能取得」或「部分結果來自較早資料」，有適用重試。初次 SQLite 匯入或資料載入顯示分組進度；本機站點索引故障提供分組重試。
- **離線與部分覆蓋**設施、探索及已裝載的站點照常返回；巴士目錄只有實際存在的快取才可用，並可按來源顯示最新取得時間。只在已知連線狀態時稱「離線」；單次服務失敗以服務狀態說明。站點詳情可提示城巴站點或反向路線覆蓋有限。沒有圖資時依目的頁原有降級。
