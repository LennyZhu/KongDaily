## 两处 UI 调整

- 铁路站名保留原双语 `PageHeading`。右侧按钮使用现有 surface／border／tint／primary Token：未收藏为白色描边，已收藏为浅绿背景及深绿实心书签；最小点击区域 44×44 pt。没有放入系统 Navigation Bar。
- 标题区允许换行，站名可伸缩，按钮换行后仍靠右；不设固定标题高度，不裁短英文站名，不关闭系统字体缩放。真实大字与长站名的视觉效果需在 iPhone 核对。
- 港铁 `line` 和轻铁 `route` 仍由原组件保存，标题按钮直接读取当前组合。切换线路即更换收藏身份，不复制收藏状态，也不修改 Repository 或唯一性。
- 无有效上下文时，标题按钮只滚动到现有线路／路线选择区；不写入收藏、不选第一条路线、不新建弹窗。选好后再次点击标题按钮才操作该组合。原有单一有效线路／路线的初始化规则保留。
- 简短按钮的无障碍名称仍含站名、具体线路／路线及收藏／取消操作；忙碌、失败与重试继续沿用原 hook。
- 「常用巴士」是真正的分区标题，右侧新增按钮沿用 `/bus` 原流程。加载、失败及无巴士收藏时也保留此入口；只看港铁、轻铁或地点时不显示巴士分区。原巴士卡片、置顶、上下移动和取消按钮未改，铁路分区未重新设计。
