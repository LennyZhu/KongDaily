# Phase 4D2 · 统一交通收藏回归与体验收尾

开工时本机 `develop` 与本机 `origin/develop` 同为 `447e51d`，工作区干净。审查包括 4D0、4D1 及 FIX1／FIX2／FIX2C 交付记录、v11 Schema、各交通 Repository、首页和收藏 UI。FIX2B 的首页刷新按钮行为以已提交代码及回归为准。

## 发现与修复

- **小巴写入与重读不原子。** 在基线注入收藏列表查询错误，先复现了取消操作返回失败、收藏与置顶却已删除的情况。小巴写入和列表重读现在共用独立 SQLite 事务，提交后才发布收藏状态及移除内存中的置顶。保存及删除的重读故障都回滚，原收藏、置顶与已发布界面状态保持一致。原有串行写入队列继续处理重试和并发。 [小巴 Repository](../src/gmb-favorites.ts) · [SQLite 与并发回归](../scripts/test-facility-favorites.cjs)
- **基线测试替身遗漏。** 全量 CJS 基线 178 通过、1 失败。探索路线导航测试在加载真实首页时缺少 4D1 引入的两个小巴模块替身。补齐替身后，原导航断言通过。这是基线测试环境问题，首页布局及实际探索导航均未修改。 [探索导航测试](../scripts/test-explore-trailhead-navigation.cjs)

除上述源文件和两份测试外，仅新增本报告。冻结的首页与收藏页布局、迁移、置顶、ETA 及功能门禁源码保持原状。

## 回归结果

| 范围 | 已核对行为 |
| --- | --- |
| 收藏及导航 | 巴士、港铁、轻铁、小巴按各自稳定身份保存和删除，重复操作不重复写入。详情和列表读取相同收藏状态。收藏不自动置顶，删除收藏释放对应位置，取消置顶保留原收藏。导航参数保留真实路线、方向及站次。 |
| 共享置顶 | 全局最多三项，可混合交通类型并跨类型移动。首尾禁用无效动作，满额提示不替换现有卡片。新增快速重复置顶与删除后排队再置顶回归。重开 SQLite 副本后相对顺序保持。 |
| SQLite v11 | v10 → v11 保留巴士及铁路记录，按旧相对顺序迁移有效置顶，三种旧模式的孤立引用均留审计记录并释放位置。验证事务故障回滚、重开、旧版升级、v11 副本恢复，以及数据库约束拒绝无目标或未开放模式。 |
| 首页 ETA | 覆盖巴士超时恢复、港铁官方方向、轻铁严格按路线筛选及多组月台预报、小巴精确停靠、计划与实时班次、重复停靠保守提示。回归涵盖失焦、后台停刷、前台恢复、缓存时效、限流退避及拒绝晚回包。 |
| 界面及语言 | 繁中和英文验证收藏分类、空状态、置顶标签、更多菜单、44 pt 触控目标和静态 VoiceOver 标签。核对首页港铁／轻铁预报共用左侧基准，铁路及小巴卡片没有可见刷新按钮。 |

## 生产门禁

电车分类和公开搜索维持隐藏，电车路线和站点直接访问呈现不可用状态，离线静态资料仍在。港九小轮的生产入口维持关闭。固定样本验证生产模式即使打开预览变量也不建立客户端，直接路由仍受保护。SQLite 收藏与置顶继续拒绝电车、渡轮模式，旧版恢复链无相应可启用记录。

iOS 静态导出主动设置 `EXPO_PUBLIC_HKKF_PREVIEW=1`。Hermes 字节码中保留电车索引和两种不可用页面文案，未发现港九小轮附近预览模块或其码头搜索标记。门禁行为另由生产模式路由及客户端测试验证。

## 剩余风险与 iPhone 验收

- 数据库测试使用固定夹具、临时数据库及已关闭副本。iOS 系统备份恢复、原生布局、VoiceOver 朗读与真实网络环境仍待真机确认。
- 使用带旧收藏及有效置顶的 v10 测试副本升级。核对旧收藏及顺序；若夹具含孤立置顶，确认其位置可重新使用。
- 轮换四种交通的首页组合，快速重复置顶并跨类型移动。检查满额、首尾禁用、取消置顶、取消收藏及冷启后的顺序。点进各卡核对实际站点及路线，再返回确认状态同步。
- 在繁中、英文、大字号及 VoiceOver 下检查站名、方向、月台、三个共享位置和更多菜单。前后台切换并断网恢复，抽查四种交通预报及门禁旧链接。
