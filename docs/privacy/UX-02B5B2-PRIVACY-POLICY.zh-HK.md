# KongDaily 私隱政策

**下一版本候選草稿** · 修訂於 2026-11-21（香港時間） · 正式生效日期待開發者確認。

本稿供審閱，涵蓋下一版本的港鐵與輕鐵功能。現行 iOS 1.0.0（Build 2）沒有這些鐵路功能，仍適用現行政策。 [現行私隱政策 v1.0](https://kongdaily-site.vercel.app/privacy/)

了解港日常如何使用位置、保存本機資料及向第三方服務查詢。

## 適用範圍

本說明涵蓋 KongDaily 的 iOS 版本、公開網站及支援電郵。KongDaily 由個人開發者 Lenny 以 Lenny Studio 品牌提供。查看巴士、天氣、附近設施或精選地點，以及使用收藏，均毋須建立帳戶。下一版本的港鐵及輕鐵目錄和列車預報亦毋須建立帳戶。

## 定位與權限

前台定位用於計算你與設施或巴士站的距離、建議附近站點，以及在附近地圖標示及聚焦位置。已有授權時，進入相關畫面可能單次讀取位置。App 沒有背景定位或位置歷史。

「交通查詢」在顯示附近巴士結果時可使用裝置定位。單純瀏覽或搜尋港鐵及輕鐵目錄毋須讀取裝置位置。

你可在 iOS 設定管理定位授權及「精確位置」。位置精度不足或拒絕授權時，仍可選地標、移動地圖或搜尋地點。iOS 定位服務及 Apple 地圖有各自的資料處理方式。

- [Apple 定位服務與私隱](https://www.apple.com/legal/privacy/data/zh-hk/location-services/)
- [Apple 地圖與私隱](https://www.apple.com/legal/privacy/data/zh-hk/apple-maps/)

## 本機儲存與搜尋

App 在裝置的 SQLite 資料庫保存巴士與設施收藏、首頁置頂、語言偏好、最多八筆巴士最近搜尋，以及官方巴士及天氣資料的快取。首頁全域搜尋在裝置上比對字詞；需要更新巴士路線目錄時，目錄請求不包含搜尋字詞。

「交通查詢」內的路線及車站搜尋亦在裝置上比對。港鐵和輕鐵的靜態目錄隨 App 提供，可離線瀏覽和搜尋。App 不會將這些搜尋字詞傳送到鐵路服務。

目前位置與附近搜尋結果可暫存在 App 記憶體。若你啟用了 iOS 備份，App 的本機資料可能隨裝置備份及還原。

## 線上查詢與外部服務

App 向九巴／龍運、城巴及嶼巴的官方服務查詢路線、站點及到站時間，按需要傳送公開路線或站點編號等查詢欄位。天氣查詢向香港天文台傳送資料類型和語言。

App 不會在上述巴士或天氣請求中附送裝置 GPS 座標或搜尋字詞。附近巴士查詢可根據裝置上的距離計算選取要查詢的公開站點。服務方可接收 IP 位址等一般連線資料。公開的接口資料未說明這些服務的查詢日誌會保留多久。

在「附近」搜尋地點時，符合條件的文字會自動透過 HTTPS 送往地政總署地點搜尋服務，可能包括你輸入的地址。App 不會在該請求附送裝置 GPS 座標。服務端可接收 IP 位址等連線資訊，並可能按其適用政策處理查詢及連線資料。地政總署公開的 API 文件沒有說明查詢是否記入日誌或日誌會保留多久。

App 內地圖由 Apple MapKit 提供。「附近」地圖可將裝置位置用作地圖標記或置中。Apple 的定位和地圖服務可依你的設定及其私隱政策處理位置及連線資料。你選擇開啟 Apple 地圖或 Google Maps 導航時，App 會交付選定目的地和步行模式。外部地圖或網站依其政策及權限處理資料。

如你主動發送支援或私隱查詢電郵，營運者會透過郵件服務接收你提供的姓名、電郵地址、問題描述及附件，以處理和回覆查詢。

KongDaily 的公開網站由 Vercel 託管。瀏覽網站時，託管商可處理 IP 位址等連線資料，以傳送網頁、營運及保護服務。網站本身沒有帳戶、聯絡表格或分析追蹤程式。

- [地政總署地點搜尋服務](https://data.gov.hk/tc-data/dataset/hk-landsd-openmap-development-location-search-api)
- [地政總署收集個人資料聲明及聯絡方式](https://www.landsd.gov.hk/tc/about-us/contact-us/collection-statement.html)
- [Google 私隱權政策](https://policies.google.com/privacy?hl=zh-HK)
- [Vercel 私隱聲明（英文）](https://vercel.com/legal/privacy-notice)

## 港鐵與輕鐵即時預報

當你在車站詳情查看即時預報，App 會按需透過香港特別行政區政府的 DATA.GOV.HK 即時資料服務查詢香港鐵路有限公司提供的列車資料。港鐵查詢傳送所選綫路及車站的公開代碼，並以固定英文選項取得回應。輕鐵查詢傳送所選車站的公開編號，並要求一併提供特別班次資料。

這些請求不附送裝置 GPS 座標、搜尋字詞、帳戶資料或 App 加入的裝置識別碼。網關及服務方可能處理 IP 位址、請求時間和一般請求標頭等連線資料。現有公開文件未說明各方是否在回應後保存或仍可查閱這些資料或所查詢的代碼，也未說明保留期限。

App 可在開啟預報、相關車站畫面回到前台或你手動更新時查詢。回應可在 App 記憶體短暫重用，不會寫入本機資料庫。過期預報不再顯示為即時資料。App 不會在背景定時查詢列車預報。

- [港鐵即時列車資料](https://data.gov.hk/tc-data/dataset/mtr-data2-nexttrain-data)
- [輕鐵即時列車資料](https://data.gov.hk/tc-data/dataset/mtr-lrnt_data-light-rail-nexttrain-data)

## 保存與刪除

你可個別移除收藏或取消置頂，並在巴士頁清除最近搜尋。官方資料快取會按功能需要更新。刪除 App 可移除本機 App 資料；卸載 App 會保留文件和資料。

iOS 備份須另從系統管理。第三方服務留存的資料依服務商適用政策及程序處理。

一般支援電郵及相關附件於個案解決後最多保留 12 個月，適用法律要求保留更長時間者除外。你可透過下方的私隱電郵地址提出刪除要求。

營運者的支援郵件刪除程序適用於營運者可控制的副本。電郵服務商獨立管理的備份、日誌及留存安排由服務商處理，營運者無法保證其刪除時間。網站託管商獨立保存的連線資料依其適用政策處理。
