## 穩定身份與更新

索引使用 `lcsd-inclusive-pet-parks + inclusive-pet-NNN`。Registry 儲存雙語名稱、地址、地區、WGS84 參考點、名單識別、範圍原文、證據連結及可精確對應的歷史 OBJECTID。現行 ArcGIS 的 global ID 欄為空。與現檔配對的歷史第二季、第三季分別有 148／181 及 4／181 筆改號。名單表格 ID、地圖碼、附表序號與 OBJECTID 均未證實為永久碼。正式配套、時段、電話及點位取自 CSDI；網站用於核實名稱與範圍及提供規則連結。

更新保留已發布 ID。比對同一雙語名稱、地址與地區，以及一米內相同參考點。來源 SHA-256 有變時列出改號、缺失、移動、身份歧義、新記錄與欄位變化並停止。發布前人工複核名單、服務公告、範圍及搬遷／拆分／合併，再更新對照表。現有 ID 對應的場地改變或自新版本消失時，構建會停止並保留舊索引。

```sh
python3 scripts/build-lcsd-inclusive-pet-parks.py --audit-only
python3 scripts/build-lcsd-inclusive-pet-parks.py
```

第一條校驗。第二條在兩來源、CRS、日期、欄位及身份通過後原子替換索引。下載、資料或匹配出錯保留舊檔。可使用帶時區的 `--input-dir` 和 `--fetched-at` 重建已保存的官方快照。
