## 首屏與搜尋

`/transport` 移除了常駐參考位置卡片及其專用樣式。原生「附近交通」導覽欄下依次為整行搜尋入口、橫向交通方式篩選、按路線／按車站切換、結果標題及原有列表。搜尋沿用白色圓角、圖示及至少 44pt 的觸控高度。原生返回、底部安全區及舊 `/bus/nearby` 的參考位置卡片沿用原實作。

| 方式 | 搜尋入口 | 結果 |
| --- | --- | --- |
| 全部 / All | 搜尋交通路線 / Search transport routes，開啟原 `/bus` | 已接入的巴士結果 |
| 巴士 / Bus | 搜尋巴士路線 / Search bus routes，開啟原 `/bus` | 已接入的巴士結果 |
| 港鐵、輕鐵、渡輪、電車、專線小巴 | 隱藏 | 顯示各自原有的未接入提示 |

篩選欄維持橫向滑動及箭頭。改變交通方式沿用現有查詢狀態，以下定位入口及距離說明只在巴士結果模式呈現。

## 定位狀態

| 狀態 | 呈現與操作 |
| --- | --- |
| 已授權並取得 GPS | 顯示附近結果。標題旁省略號的無障礙名稱為「更改參考位置 / Change reference location」，可直接展開原地標清單。 |
| 定位中 | 結果標題下顯示「正在尋找附近交通… / Finding nearby transport…」。尚無位置時仍可選擇地標。 |
| 未授權或可再請求 | 保留搜尋入口。結果區提供「使用目前位置」及「選擇地標」，權限對話框由用戶按鈕觸發。 |
| 系統阻止再次請求 | 現有定位服務確認權限被封鎖後，結果區提供「開啟設定」及地標入口。設置啟動失敗時顯示當前語言的提示。 |
| 定位服務關閉、失敗、超時或精度不足 | 沿用對應提示，提供重試或選擇地標。自動更新失敗時，先前 GPS 結果不再顯示為目前位置。 |
| 已手動選擇地標 | 結果標題下顯示地標名稱。手動選擇仍取消進行中的 GPS 請求，從省略號可再次更改地標或主動切回 GPS。 |

沿用 UX-01A 的前台定位、重新聚焦及回到前景觸發、超時、取消和請求去重。距離控制顯示當前範圍，仍可選擇 500 米、1 公里及 2 公里。旁邊的 ⓘ 展開直線距離和原有覆蓋說明，按路線及按車站各用適用文案。

## iPhone 人工驗收

1. 在 iPhone 17 Pro 及較小 iPhone 由首頁開啟附近交通。在兩種語言核對搜尋、交通篩選、分段和列表順序。切至「巴士」及其中一種未接入方式，核對搜尋顯示與返回。
2. 已授權時檢查自動定位、離開再返回、前後景及定位中提示。有結果時試用省略號選擇地標，核對距離資料更新，再從省略號切回 GPS。
3. 使用未授權、已封鎖及定位服務關閉情境。核對可正常搜尋、權限只在點按後請求、設定入口及地標備援可用。
4. 在大字模式和 VoiceOver 下確認搜尋、範圍、ⓘ 及更改位置操作。確認 500 米、1 公里及 2 公里可選，列表可滾至底部。
