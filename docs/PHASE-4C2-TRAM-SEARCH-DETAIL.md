## 静态目录及全域搜索

`/transport` 的「電車 / Tram」分类复用既有交通分类、搜索框和按路线／按车站切换。空查询按当前视图列出 6 条路线或 117 个站点。可输入繁中或英文路线名、站名。此分类使用本地索引，选中时无额外定位请求、半径筛选或距离信息。正常空结果与目录读取失败分别提示。

全域搜索及交通「全部」的文字搜索共用注册表。电车新增独立路线和站点类型，分别使用电车及站点图标，标注类型及官方站点编号。新来源排在已有交通来源之后，继续使用原来的跨来源排序规则。路线结果持有官方路线与各方向，站点结果持有官方站点与其全部停靠。同名站仅按各自官方 ID 进入详情，用户可区分上環西港城 `99140` 和 `99212`。

## 详情、站序及运营显示

- 路线与站点均通过 `/tram/[kind]` 进入。站点页列出静态目录中的每次停靠，可选择路线及方向。路线页仅在方向、站点 ID 和站序三者匹配时高亮对应停靠。使用原有返回栈和搜索恢复机制。
- 路线详情显示运输署路线名、实际起点及终点、现有方向选择样式、完整站序和官方来源。东／西行按 4C0 核实结果标注，跑马地线路注明是主线方向。进出支线独立展示，各自保留真实顺序、停靠键及静态上下车限制。没有合成循环续乘或替代站序。 [4C0 方向及站序核对](PHASE-4C0-TRAM-DATA-VALIDATION.md)
- 石塘咀总站 `99313` 仍可搜索、仍列在 4004／4005 静态站序，显示「暫時關閉」且隐藏该站的静态上车标识。路线及车站详情都提供双语替代安排、核实日期、营办商署名和公告链接。2026-11-23 复查时官网仍列关闭公告，继续采用 4C1 的覆盖。07E 和 94W 维持公告说明。 [营办商公告](https://www.hktramways.com/en/service-updates-detail/141/en/press-releases)
- `active` 与 `unknown` 分为「已核實營運」与「營運狀態未核實」。路线页用一条说明解释其未标记站点，站点页显示明确状态。界面使用「路線及車站資料 / Route and stop information」说明静态性质，保留运输署双语署名及快照日期。 [运输署静态资料](https://data.gov.hk/en-data/dataset/hk-td-tis_14-routes-fares-xml)

## iPhone 人工验收

1. 进入交通页「電車」，核对默认六条路线，切换车站后搜索「上環街市」或 `Western Market Terminus`。确认两个站点分别可打开，返回保留关键词和当前视图。
2. 从首页全域搜索「堅尼地城 跑馬地」或 `Kennedy Town Happy Valley`。打开路线切换两个方向，核对目的地及官方站序。再搜跑馬地總站，选一条具体方向，核对详情选中了该方向及对应停靠。从详情返回首页搜索。
3. 搜「石塘咀總站」，核对暂时关闭、替代乘车说明与公告链接。另开跑馬地總站核对状态未核实。路线 4004／4005 应仍可打开原静态资料。
4. 繁中、英文及大字号下查看长站名和可点击区域。已加载的 App 可用飞航模式复核电车目录、站点与路线详情。
