## 四项置顶与迁移

v11 的共享置顶表有 `CHECK (position BETWEEN 1 AND 3)`，需要迁移。v12 在既有独占事务内将旧表暂时改名，建立位置 1–4 的表，复制全部旧置顶、位置和身份，并恢复原有唯一约束、合法类型检查、目标收藏存在检查、禁止直接更新及取消收藏清理触发器。只替换共享置顶表，其他业务表保持原数据。历史巴士表的旧 `pin_order` 约束继续保留；当前共享排序来自 `home_transport_pins`。

迁移失败时事务回滚并允许重试。第四项通过原 Repository 写入，第五项由 Repository 上限拒绝，直接写入位置 5 也被 SQLite CHECK 拒绝。所有正式交通共用四项，可跨类型调整顺序。收藏数量独立于置顶名额。

首页卡片列表已经按有效置顶动态生成，0–3 项时显示新增入口，4 项时整颗入口移除，读取期间继续抑制错误闪现。「查看全部收藏」保留。卡片样式及其他首页区域沿用原设计。

自动 ETA 由每个挂载卡片的既有 Hook 执行。下拉刷新注册当前卡片的既有刷新回调，不含硬编码三项截断，第四项自然参与。未改 ETA Provider 或刷新调度，继续遵守请求合并、冷却、退避、连接及响应体超时，个别失败独立结算。

## 四档距离与状态

新页面默认 300 米，选项为 300 米、500 米、1 公里、2 公里。英文为 300 m、500 m、1 km、2 km。原页面没有落库的半径偏好，仍使用页面状态保存选择；分类、路线／站点切换和返回保留选择。手动改用地标也不重置明确选择的半径。

空结果按 300 → 500 → 1000 → 2000 米依次提供扩大入口。2 公里停止扩大。菜单沿用等分按钮、颜色及 44 pt 点击高度，增加允许换行的布局。标题工具栏及直线距离说明沿用原实现。

巴士查询参数、铁路坐标合法范围检查和小巴半径过滤均接受 300 米，使用原 Haversine 计算及未舍入距离。全部分类继续合并四交通完整候选、统一排序后交给 FlatList 虚拟渲染。附近生活设施地图的距离策略保持原实现。

## iPhone 验收与限制

1. 从含三项置顶的已发布版本升级，核对收藏与顺序，加入第四项并尝试第五项。检查繁中／英文满额提示和首页最多四张卡片。
2. 在收藏页跨交通移动第四项，取消置顶及取消收藏，确认四项降至三项后新增按钮立即恢复。重新置顶并冷启，核对顺序与无闪现。
3. 以巴士、港铁、轻铁、小巴各一项测试首页自动刷新和下拉。试连续下拉、断网、恢复网络及前后台切换，确认四项各自收尾。
4. 首次打开附近交通确认默认 300 米，在全部及各正式分类查看路线与站点。选择其他半径后切分类、切模式、进详情返回及选择地标，确认保留半径。
5. 在无结果位置逐级扩大到 2 公里，确认停止扩大；检查中文、英文、大字号菜单的文字、触摸与 VoiceOver。抽查地图、Tab 滑动及隐藏功能门禁。

自动测试使用真实发布 Schema 配合合成数据，签名候选的实际设备升级、原生动画、四卡片网络耗时和最大字号视觉仍待 iPhone 验收。本轮未部署同源支援文案。
