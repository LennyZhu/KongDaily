## UI-04 产品规则（已讨论，待最终确认）

1. 地图 / 列表必须能切换；默认优先地图，具体在高保真确认后锁定。
2. 上方分类：全部 / 公厕 / 宠物公园 / 公园 / 巴士。巴士先跳转已实现附近巴士模块，避免假装已有地图巴士图层。
3. 不主动弹定位权限；可手动选香港区域，用户点击「使用目前位置」时才申请单次权限。
4. 一个实际地点应为一个主展示卡，但多数据来源之间仅在有充分证据时合并；保留原始官方 ID。
5. 设施服务状态未知时不得写「营业中」；宠物规则必须有官方依据；直线距离不得冒充步行距离。
6. 地图加载失败仍支持本地列表，断网不保证地图瓦片可用。
7. 天气警告/公园暂时关闭等动态声明，仅在来源核实后展示。不得默认为公园开放。
