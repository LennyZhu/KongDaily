## 更新

Registry 仍使用 `source + officialId`。內部鍵永久分配。雙語名稱、地區、地址和 1 米內的點位共同匹配，只容許匯出捨入，保留經確認的舊版 OBJECTID 證據。下載、結構、範圍或身份校驗出錯，保留舊索引；官方異動由建置腳本輸出差異，先人工檢查再更新 Registry。
