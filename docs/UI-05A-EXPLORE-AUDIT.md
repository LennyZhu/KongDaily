## 3. 官方來源與可用性

郊野公園遠足徑目錄列有繁中／英文資源及 CSDI API，官方更新頻率為有新增記錄時。本輪核對了目錄，尚未核對圖層逐筆穩定身份、坐標參考系統、入口欄位及雙語完整度。郊野樂行的龍脊頁標示土地灣港島徑第八段入口為起點、大潭峽為終點，並分列起點、終點、巴士站和 GPX。「港島徑第八段」另有不同終點的行程。同一段山徑可以屬於不同行程，發佈時須選定官方記載的行程及方向，再驗證導航點。此輪未核實龍脊的導航坐標，也未逐條核對官方英文路線頁。[雙語資料目錄](https://data.gov.hk/en-data/dataset/hk-afcd-afcdlist-hikingtrailscp/resource/4186314e-8a12-452c-b8c8-9d60eadce640)、[郊野樂行龍脊](https://www.hiking.gov.hk/trail/info/id/UWgvZytZSlRrcnBJSU5DWVZUa2pyUT09/map_type/1)、[港島徑第八段](https://www.hiking.gov.hk/trail/info/id/QVVxLzJWeGxNUndtYUNXY2VpK3QxUT09/map_type/1)

另有封閉山徑 CSDI 資料，標示有更新時發佈。郊野樂行公告有「直至另行通知」及只涉及部分路段的記錄，須核對公告範圍及是否撤銷。網站文字、地圖、相片及影片的商業重用需事先書面授權。官網提供 GPX 下載，這次未確認把 GPX 隨商業 App 分發的權利。CSDI 開放資料須另按該平台及圖層條款審查。[封閉山徑資料目錄](https://data.gov.hk/en-data/dataset/hk-afcd-afcdlist-cpclosedtrailcsdi)、[郊野公園設施公告](https://www.hiking.gov.hk/news)、[版權告示](https://www.hiking.gov.hk/content/copyright_notice)、[相片使用](https://www.hiking.gov.hk/content/use_of_photo)

### 康樂及文化事務署（LCSD）場地與節目

- **公園、動植物公園及花園。** 官方目錄提供機讀位置資料與多格式下載／API，有新增記錄時更新。專案上一輪審計已核對雙語名稱、坐標及 `OBJECTID` 曾重編，現有索引以 Registry 保持身份。探索可將圖層作為個別場地的核對來源，選入時應檢查是否與附近的現有記錄重疊。場地目錄更新和場地暫停開放分屬不同資訊，須核對場地公告。下載依開放資料條款，康文署一般網頁圖文另受網站版權告示約束。[官方目錄](https://data.gov.hk/en-data/dataset/hk-lcsd-csdi-parks-zoos-gardens)、[專案資料審計](ui-04c-official-data-audit.md)、[康文署網站重要告示](https://www.lcsd.gov.hk/en/notice.html)、[康文署新聞稿](https://www.lcsd.gov.hk/en/press_release/index.html)
- **文化節目。** 官方目錄標示每日更新，提供節目、節目舉辦日期、場地及場地休息日四份 XML。資料字典列出節目 `id`、場地 `venueid`、雙語標題及場地名稱、場地經緯度，以及節目日期 `indate`。部分日期說明、演出時長及票價為文字欄位。可用節目 ID 及場地碼關聯資料，實際坐標語義、欄位缺值、跨期 ID 和雙語完整度仍須用樣本驗證。資料字典未見結構化逐場取消或改期欄位，場地休息日只描述場地。圖片 URL 需另確認權利才可存入 App。[文化節目資料目錄與 XML 下載入口](https://data.gov.hk/en-data/dataset/hk-lcsd-event-event-cultural)、[官方資料字典](https://www.lcsd.gov.hk/datagovhk/event/data_dictionary.pdf)

## 5. 推薦 1.0 範圍

**推薦方案 A。** 規劃首批 8–12 個核實地點，實際上架數由證據決定。探索 Tab 先提供「精選景點／行山郊遊／海濱休閒」，並標示地區。當同一地區有足夠地點才增加地區篩選。首版交付雙語名稱、短介說明為何值得去、交通提示、官方來源與核對日期，以及以核實目的地開啟外部地圖。官方已確認的免入場費等常設資訊可選擇性納入，標明適用範圍與條件。

這個範圍以隨 App 發佈的內容包提供離線瀏覽，無需額外後端及資料庫遷移。龍脊和西九文化區先作為候選。龍脊須確認官方行程、起點坐標及最新通行資訊。西九須先選定單一具名場地並驗證目的地。兩張首頁卡已有授權紀錄，若延用至探索內容，仍需核對照片確實拍攝該地及當前用途的署名、裁切和授權要求。[既有首頁圖片來源](../assets/home/credits.md)

延期項目包括活動列表、即時開放、預訂、步道內導向、全港設施地圖、全局搜尋整合和獨立探索收藏。獨立探索收藏需另確認持久 ID、`地點` 類別是否混排以及資料退役時的快照規則。若獲批的探索地點也有已核實的附近設施身份，仍可沿原有附近入口收藏該設施。

若後續試行 B，先選單一官方活動來源。以 `Asia/Hong_Kong` 處理已核實的場次開始與結束時間，同時保存場次身份、官方連結、資料取得時間和取消／改期證據。只憑日期或活動時長無法判斷目前是否正在舉行。僅在官方確認費用與適用條件時標示「免費」。活動頁須能在來源過舊或離線時隱藏時效性項目，並由維護者在試行前確認日常巡檢及緊急更正方式。

## 6. 內容資料與發佈門檻

| 風險 | 建議控制 |
| --- | --- |

| 文字與照片權利 | 留存作者、原始連結、授權版本、允許的商用／本地保存／再分發方式、修改紀錄及署名文案。對現有龍脊照片保留適用的 CC BY-SA 4.0 條件。證據不足時選用可用的無圖狀態。 |
| 資料變更和離線回歸 | 版本化內容，發版檢查雙語、唯一身份、有效坐標、官方連結與素材權利。驗證失敗時保留最後一份通過審核的內容，另列需人工更正的項目。 |

## 7. UI-05B 設計建議

- 保留四個主 Tab 和首頁既有佈局。探索列表用可辨識的分類、地區、名稱和一句亮點。可用簡潔無圖卡片，照片有授權且確有助辨認時才使用。
- 地點短詳情按「值得去的原因、如何到達、出發前查閱」排列。優先給官方交通說明和已核實的外部導航入口。行山頁應清楚分辨起點、終點及當前可取得的官方通行公告。
