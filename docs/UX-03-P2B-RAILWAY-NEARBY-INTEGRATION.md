## 接入及距离语义

- 按车站：港铁复用 Phase 2A 最近已核实入口距离；轻铁使用官方站点参考位置。按真实、未取整的直线距离排序／筛选，再用既有格式显示米或公里。卡片明确区分「最近入口」与「站点参考位置」，不表示步行路径、入口开放或具体月台。
- 按路线：以附近车站的 `memberships`／`routes` 反查既有线路，每条线路只出现一次，推荐距离最近的车站。车站卡仍保留全部所属线路；详情使用既有 `/mtr/[kind]`、`/light-rail/[kind]`。没有反转列表或改写 705／706、分支及重复站序。
- 「全部」直接合并原巴士路线／站点组和铁路结果，以距离及稳定 ID 排序。铁路 ID 包含交通方式、条目类型和业务 ID，重铁／轻铁同名站不合并。巴士沿用原适配器、推荐站和 ETA 可视条目机制；未接入类别仍显示原占位提示。
- 三交通使用同一位置和半径。被动位置刷新时，若巴士查询尚未完成，铁路与仍可见的巴士结果共同保留上一有效参考点，待新查询就绪后一起更新。切到铁路分类后显示当前铁路结果，迟到的巴士查询不会覆盖铁路类别。
- 半径保持 **500／1000／2000 米，默认 500 米**。零结果显示当前范围及主动扩大范围入口，不自动扩大；无有效位置显示定位问题／手动选择入口，不解释成附近没有铁路。
- 坐标为静态 JSON import，已随本次 Hermes 导出打包。距离说明内加入地政总署 iGeoCom 署名；没有远端地理下载或上传用户坐标，也不为附近铁路批量请求 ETA。实时预报继续由原详情页按需加载。

## GPS、搜索与返回

保留 UX-02B5A2 的定位范围保护，启用条件改为：正在显示已接入交通的**附近结果**，且没有文字搜索、没有进入全港铁路目录。附近分类之间切换不改变该启用条件，因此不会重复启动 GPS；按路线／按车站和半径切换也不另发定位请求。

进入搜索、全港目录、离开页面或进入背景时，沿用原 cleanup、请求取消及迟到结果忽略逻辑。详情返回／前台恢复仅在附近模式按既有权限策略尝试一次刷新；手动地标继续优先，不自动请求权限。被动刷新保留有效位置和列表；确认新定位失败后沿用原错误及回退行为，不展示猜测距离。

铁路「查看全部／View all」复用同页目录，可切回附近；纯目录及文字搜索不启动 GPS。搜索不限半径，清空后恢复当前交通类别的附近结果。实际代码原先只查询巴士路线，本轮按任务要求复用现有 `loadGlobalBusStops`／`searchBusStops` 和结果行补齐巴士站查询，直接打开现有巴士站详情；适配器的数量上限、失败和重试保留，超出上限时提示缩窄搜索。**首页全局搜索模块及页面未修改。**

保留 UX-02A5 的 `useTransportListPosition`，没有修改该 hook。铁路附近列表用交通方式、浏览模式、主动参考位置修订及半径构成 scope，被动 GPS／ETA 更新不更换列表 key；原稳定条目跟随、重排恢复及拖曳取消机制继续生效。

## iPhone 人工验收

1. 授权前台定位进入 `/transport`，分别选择港铁／轻铁。核对默认为附近结果，范围 500 米；切换按车站／按路线及 1000／2000 米，确认车站排序、线路去重及推荐站合理。
2. 在中环／香港、金钟等区域核对换乘站仅一张站点卡、所属线路完整、中环与香港站独立；港铁距离标为最近入口直线距离。分别进入线路／车站详情，核对原实时预报及返回手势。
3. 手动选「港鐵元朗站」或使用轻铁服务区域 GPS；核对轻铁站点参考距离、海皇路 `250` 详情、705／706 原方向和重复站序。距离不得被称为月台位置。
4. 在元朗选择「全部」，核对巴士、港铁、轻铁类型标签、同一范围、按距离混排及各自详情入口；巴士 ETA、车费、限定服务和收藏行为维持正常。
5. 在中环选择轻铁，确认无附近结果而非展示全港 11 条路线；范围不会自动扩大。拒绝定位或关闭定位服务，确认错误说明、手动地标和全港搜索仍可用，不展示虚假附近距离。
6. 搜索远于当前范围的铁路站、巴士路线及巴士站，进入详情后返回保留搜索词与位置；清空回附近。铁路「查看全部」可离线浏览，并从详情返回／前后台恢复，不启动附近 GPS。
7. 将附近列表滚动后进入详情并返回、切后台再回来；确认不闪空、不反复回顶、手动地点优先。快速切交通分类及搜索／清空，确认没有多次 GPS 或串类结果。
8. 切换 zh-HK／English，检查小屏、大字的距离和上车站文字换行、按钮触控及底部安全区。飞航模式验证已缓存巴士资料与离线铁路附近／搜索；恢复网络再验原详情实时预报。

本轮没有操作模拟器或真机；原生视觉、滚动像素、权限面板和实际网络体验以上述人工验收为准。
