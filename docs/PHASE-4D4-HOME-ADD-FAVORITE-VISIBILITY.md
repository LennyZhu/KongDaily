# Phase 4D4 · 首页新增常用交通入口

## 修改文件

- [首页](../src/app/(tabs)/index.tsx) 复用已匹配置顶收藏的首页卡片及共享名额上限。有效置顶为 0、1、2 时显示「＋新增常用交通」，达到 3 项时整颗按钮从布局中移除。「查看全部收藏」和「生活快捷入口」保留原布局。
- [首页 UI 回归](../scripts/test-global-search-ui.cjs) 覆盖繁中、英文、0–3 项、加载期间、收藏数量大于置顶上限、孤立置顶及满额后仍可进入收藏页。
- [收藏与 SQLite 回归](../scripts/test-facility-favorites.cjs) 覆盖混合交通置顶，以及取消置顶、重新置顶和删除收藏后首页读取最新状态。

首页从原有订阅读取置顶与收藏，只统计已匹配到收藏的卡片。加载中或读取失败时暂不显示新增入口，避免把临时空列表视为有空位。SQLite、收藏 Repository、排序、卡片样式和 ETA 逻辑沿用现有实现。

## 自动验证

- TypeScript、两套定向回归、iOS Metro 生产模式静态导出及 `git diff --check` 均通过。导出产物已确认为 Hermes 字节码。
- SQLite 回归涵盖旧库升级、孤立置顶清理、三项上限、跨交通排序及重新打开数据库后的持久化。

## iPhone 人工验收

1. 依次设置 0、1、2 个首页置顶，确认均显示新增按钮。收藏总数超过三条时，仍以实际置顶数为准。
2. 从收藏页加入第三项置顶后返回首页。确认新增按钮消失，「生活快捷入口」上方无多余空白，「查看全部收藏」仍可用。
3. 取消一项置顶后返回，确认按钮恢复。重新置顶到三项，再删除一项已置顶收藏，确认按钮再次出现。
4. 在三项置顶时退出并重启 App，观察启动加载期间是否闪现新增按钮。切换繁中与英文，确认可用状态下的按钮文案与跳转正确。
