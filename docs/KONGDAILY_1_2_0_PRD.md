## 版本目标

完善香港公共交通的日常使用体验：快速发现附近交通，收藏经常乘搭的路线与车站，在首页查看常用公共交通实时预报，通过全局搜索查找已接入的交通、设施和地点，并使用更多香港公共交通服务。同时精简现有附近设施页面。

## 冻结需求

### UX-03-01：统一交通收藏与搜索

- 港铁、轻铁支持收藏「线路＋车站」组合；需要时记录可核实的行车方向。不影响现有巴士收藏数据。
- 收藏页统一管理巴士、港铁、轻铁；首页「常用公共交通」显示收藏服务的实时预报。
- 首页全局搜索加入港铁、轻铁路线和车站，尽可能复用 `/transport` 的数据源和搜索适配器。
- 建立统一搜索数据源接口，后续交通数据通过该接口接入，避免重复编写首页搜索逻辑。
- 实时请求沿用已有按需加载、过期及限流策略。

### UX-03-02：铁路附近查询

- 港铁、轻铁按当前位置查询附近车站，并根据车站反查可乘搭线路；「全部」模式整合巴士、港铁、轻铁。
- 保留 500／1000／2000 米范围，默认 500 米；保留手动地点选择及全港搜索。
- 只使用经过核实的车站或出入口坐标，距离明确标为直线距离，不冒充步行距离；无可靠坐标时不伪造附近排序。
- 附近查询以静态目录和坐标索引为基础，不为了生成附近列表大量请求实时 ETA。

### UX-03-03：新增三种交通方式

| 方式 | 交付范围 | 实时数据边界 |
| --- | --- | --- |
| 专线小巴 | 官方路线与车站、附近查询、接入现有交通搜索 | 官方实时 ETA，仅在实际覆盖范围内提供。 |
| 渡轮 | 官方航线、码头及班次，附近码头与航线查询、接入交通搜索 | 有可靠实时接口的营办商提供实时预报；静态开航时间与实时 ETA 明确区分。 |
| 电车 | 官方线路、车站与站序，附近车站及线路搜索、接入交通搜索 | 仅在存在可靠且适用的数据来源时接入实时 ETA。 |

三种方式均复用现有 `/transport` 和统一全局搜索能力，不另建独立交通查询首页。各阶段先核实官方来源、覆盖范围、坐标、更新时效及再利用条件，再接入实际可用的数据；不承诺未经核实的覆盖或实时能力。

### UX-03-04：附近生活设施页面精简

- 删除顶部副说明的实际 UI 渲染，繁中和英文同步移除，搜索框自然上移，不保留固定高度空白。
- 删除分类栏「巴士」及其专属跳转；只保留全部／公厕／宠物公园／公园，保持其样式和真实筛选行为。旧 `bus` 分类安全回退到 `all`。
- 标题「附近生活設施」及信息按钮、搜索、地图／列表、MapKit、标记及聚合、GPS、手动地点、地图中心移动、列表与详情导航、底部 Tab 均维持原行为。
- 地图和列表使用相同设施类型筛选；不改设施数据源、首页交通入口、全局搜索或巴士／港铁／轻铁业务逻辑；保持其余中英文、配色与布局，不为未来分类重构。
