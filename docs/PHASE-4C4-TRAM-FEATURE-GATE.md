# Phase 4C4 · 暂缓公开香港电车功能

香港电车分类、公开搜索结果和详情暂未开放。4C0–4C3 的离线快照、搜索及附近查询实现均保留，包括 6 条路线、12 个方向、117 个站点、427 条停靠记录和石塘咀运营状态覆盖。 [4E0 授权调查](PHASE-4E0-TRAM-ETA-LICENSING.md)

## 开关和导航

- [`tram-feature.ts`](../src/tram-feature.ts) 定义唯一的源码开关 `tramFeatureEnabled`，当前为 `false`。正式版和默认开发构建行为一致。深链接参数、用户设置和环境变量均不能开启。回归测试通过模块替身验证重新开放时的路径。
- [分类组件](../src/components/transport-ui.tsx) 从横向列表移除电车项，其余分类沿用原顺序及滚动规则。[附近交通](../src/app/bus/nearby.tsx) 在渲染前把旧电车选择视为「全部」，不清除已有查询和定位状态。当前分类在页面内部管理，现有路由没有持久化电车分类参数。
- [统一搜索](../src/global-search.ts) 在执行查询和合并分页之前跳过电车数据源。首页全域搜索与交通页共用此规则，路线和站点均不计入结果或数量。[搜索导航](../src/global-search-navigation.ts) 也拒绝旧电车结果。
- [电车详情共用路由](../src/app/tram/%5Bkind%5D.tsx) 保留注册，先检查开关，再解析和读取路线或站点。直接访问、深链接和旧导航栈恢复均进入同一[双语](../src/i18n.ts)不可用页面，可以正常返回或继续使用 App，不触发重定向。离线快照仍随 iOS 导出打包。

## 4D 范围

[1.2.0 PRD](KONGDAILY_1_2_0_PRD.md) 已记录新范围。专线小巴收藏与首页置顶继续开发。电车收藏与置顶暂缓。渡轮仍须通过既有授权和生产门禁。巴士、港铁、轻铁收藏与全局三个共享位置保持现状。本轮未修改 SQLite 或任何收藏数据。

## 验证与人工验收

更新了 `scripts/test-nearby-bus-location.cjs` 及现有全域搜索、搜索 UI 和导航测试。覆盖两种语言的分类次序、旧电车选中状态回退、两种搜索来源过滤、旧结果导航拦截和路线／站点深链接。既有电车功能测试以测试开关继续运行，离线数据层回归也保留。

`npm run typecheck`、94 项定向回归、iOS Metro／Hermes 生产静态导出及 `git diff --check` 均通过。导出生成单个 iOS `.hbc` 文件（7.1 MB），产物位于临时目录。

人工验收可分别在繁中及英文检查分类横向滚动、以电车路线或站名搜索、打开旧路线和站点链接并返回，再抽查巴士、港铁、轻铁及专线小巴查询。真机布局和系统深链接交给人工验收。

## 重新开放条件

取得允许在商业 App 使用实时资料的正式书面授权，确认访问、限流、缓存、署名及覆盖范围。接入获授权的实时 ETA，验证官方站点和方向映射、异常与过期行为。通过原有静态、附近、搜索、详情及发布构建回归后，才在统一源码开关重新开放。电车收藏和置顶另行验收。
