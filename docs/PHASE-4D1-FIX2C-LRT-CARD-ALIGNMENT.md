# Phase 4D1-FIX2C · 首页轻铁卡片正文对齐

## 修改文件

- [`home-favorite-railway.tsx`](../src/components/home-favorite-railway.tsx) 移除轻铁正文额外的 40 pt 左侧缩进，港铁与轻铁共用正文容器。两组方向、月台及「預計到站」从卡片的常规内容边距起排。站名标题仍在图标右侧。
- [`test-mtr-next-train.cjs`](../scripts/test-mtr-next-train.cjs) 在繁中及英文下验证共用正文样式、方向与 ETA 的列间距、右对齐及文字换行规则。

轻铁保留每条预报的列间距、行距和右对齐 ETA。正文得到更多宽度，长方向和大字号仍可自然换行。改动不增加行高，ETA 数据、路线筛选、月台及到站语义继续沿用原逻辑。

## 验证

TypeScript、32 项定向回归、iOS Metro／Hermes 静态导出及 `git diff --check` 均通过。回归覆盖首页铁路预报、双语、可换行样式、收藏与共享置顶。未启动模拟器、创建 EAS Build 或提交 Git。

## iPhone 人工验收

1. 首页同时放置一张港铁卡和一张有两组预报的轻铁卡。比较两张卡分隔线下方文字的左侧基准，并确认轻铁分钟数仍贴右。
2. 分别切换繁中、英文和较大辅助字号。确认两组方向、月台及预计到站说明完整可读，长方向自然换行，文本和 ETA 保持间距。
3. 点进轻铁卡核对对应线路和车站详情，再返回首页查看卡片。实机布局待验收。
