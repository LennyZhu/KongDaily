# UX-01A 附近巴士自動定位

## 根本原因

`/bus/nearby` 原先只在點按「使用目前位置」時呼叫定位服務。頁面進入或重新聚焦時，焦點回呼只初始化載入狀態及註冊清理。因此，即使 iOS 已授予前台定位權限，新開頁面仍需要手動點按。

## 定位時機與資料處理

- 頁面初次聚焦、從詳情返回聚焦，或頁面仍聚焦且 App 從背景回到前景時，檢查定位服務及現有前台權限。已有授權時呼叫既有服務取得一次位置，成功後更新「參考位置」，由原有查詢流程載入附近車站及可乘搭路線。iOS 暫時 `inactive` 後回到 `active` 不會重啟定位，讓原有的權限提示可正常完成。參考 [Expo Router 焦點回呼](https://docs.expo.dev/versions/v57.0.0/sdk/router/#usefocuseffecteffect-do_not_pass_a_second_prop)及 [React Native AppState](https://reactnative.dev/docs/appstate)。
- 自動流程以 `allowPermissionPrompt: false` 呼叫原服務。首次尚未授權時，使用者可透過「使用目前位置」主動提出權限請求。系統已封鎖時提示設定或改用地標。定位服務關閉、取得位置失敗、逾時、位置精度不足或超出香港服務範圍時，沿用現有雙語提示及重試入口。
- 每個可見頁面同時只處理一個有效定位請求。失焦、卸載、進入背景及選取地標時取消該請求。以 `AbortController` 和請求身分檢查阻止遲到的結果寫回畫面。Expo 已發出的單次原生定位可能在取消後才返回，頁面會捨棄結果。參考 [Expo Location 單次位置 API](https://docs.expo.dev/versions/v57.0.0/sdk/location/#locationgetcurrentpositionasyncoptions)。
- 開始重查時清除舊的 GPS 參考點和對應的畫面結果。未新增 GPS 快取或持久化。沿用原服務的 12 秒取點期限、150 米精度上限及香港範圍校驗。切換「按路線／按車站」共用已取得的位置，重新聚焦時保留列表模式及已選搜尋半徑。
- 手動地標會立即成為參考位置，並在同一頁面實例重新聚焦或回到前景後保留。使用者可點按「使用目前位置」切回 GPS，定位失敗時仍保留已選地標。頁面卸載後不保留地標，延續原有的非持久化行為。
- GPS 座標只交給既有本機車站查詢。該流程使用 SQLite 範圍查詢再按直線距離篩選及排序。現有營辦商資料更新與 ETA 維持原有請求和資料欄位。

## iPhone 人工驗收

1. 在 iOS 設定允許 KongDaily 使用 App 期間定位。從巴士查詢進入附近巴士，確認無需點按，參考位置變成「目前位置」並顯示結果。
2. 切換「按路線／按車站」及搜尋半徑，確認無額外定位載入。打開路線或車站再返回，確認重新定位並保留剛才的模式與半徑。完全退出附近巴士再進入，確認仍會自動定位。
3. 保持附近巴士在前台，切到其他 App 再返回，確認只刷新一次。快速進出附近巴士，確認沒有卡住或出現舊位置。
4. 在尚未授權的環境進入附近巴士，確認頁面不自行彈出系統授權。點按「使用目前位置」後應由系統提出授權；拒絕後仍可選地標。關閉系統定位服務時，確認有提示並可使用地標，重新開啟後可重試。
5. 在定位進行時選擇地標，確認回傳較晚的 GPS 結果不會改寫地標。從詳情返回和背景恢復時地標仍保留。點按「使用目前位置」並成功後應切回 GPS。
6. 使用繁中和 English 檢查定位狀態及提示，確認附近結果仍按直線距離排序，原有路線及車站入口正常。

本輪尚未驗證 iOS 真實權限提示、背景切換、原生定位或畫面呈現。
